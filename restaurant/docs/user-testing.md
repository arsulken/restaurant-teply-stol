# Протокол пользовательского тестирования

Статус: реальные сессии ещё не проведены. Не заполнять результатами автоматических тестов.

Пригласить 5 участников вне команды. Использовать коды У1–У5. Один ведущий зачитывает задания без подсказок, второй фиксирует время, успех, подсказки и замечания. Не записывать персональные данные. Планируемая длительность — 15–20 минут на участника.

## Задания

1. Найдите пасту и прочитайте состав.
2. Зарегистрируйтесь и добавьте две порции блюда.
3. Оформите заказ с комментарием.
4. Найдите свой новый заказ и отмените его.
5. В демонстрационном аккаунте администратора измените остаток блюда и переведите новый заказ в приготовление.

Для задания 5 ведущий заранее подготавливает новый заказ. Не объяснять расположение кнопок.

После каждого участника: «Оцените удобство от 1 до 5» и «Что было самым непонятным?». После всех сессий вычислите долю заданий без помощи и медиану времени каждого задания.
