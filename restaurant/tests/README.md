# Проверки проекта

Серверные: из корня проекта в активированной Python-среде выполнить `python -m unittest discover -s tests -v`.

Браузерные: нужен Node.js 20+ и отдельная чистая база. Остановите API и запустите его с переменной RESTAURANT_DB, указывающей на новый файл. Также запустите фронтенд на 8080. Затем в папке tests выполните `npm install`, `npx playwright install chromium`, `npm test`. Можно вместо загрузки браузера указать CHROME_PATH с путём установленного Chrome.

Сценарий меняет демо-данные: создаёт заказ, меняет состав, статус и остаток. Он рассчитан на восемь исходных блюд и пустую корзину. Не запускайте на нужных вам данных. Результат и снимки сохраняются в docs. Версия Playwright для повторного запуска закреплена в package.json, фактический первый прогон использовал пакет из среды подготовки и установленный Chrome.
